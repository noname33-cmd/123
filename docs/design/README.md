# Design 01 — Truck Route & Savings

Первое визуальное направление, 17 октября 2026. Это HTML-прототип для обсуждения мобильного интерфейса; production React Native приложение не изменено.

Откройте `prototype.html` в браузере напрямую. Установка зависимостей и сервер не нужны. Сохраняйте расположение файла относительно `../../assets/brand/truck-route-savings-logo-v1.png`. Внешних шрифтов, сервисов и сетевых API нет.

## Экраны и взаимодействия

- **Вход:** email/password только для чтения; вход, восстановление пароля и регистрация недоступны. Не вводите реальные учётные данные. Провайдер авторизации ещё не выбран.
- **Главная:** профиль устройства и явные состояния отсутствия truck routing и данных экономии. Карточка открывает профиль; реальные маршруты, карты, тарифы и суммы не показаны.
- **Профиль:** rigid truck без прицепа и tractor + one semitrailer; переключение US/metric. Validate/Save показывают только переход состояний макета. Проверки доменного модуля здесь не вызываются; данные никуда не сохраняются и не отправляются.

Все значения — фиксированные синтетические примеры, одинаковые для обоих типов транспорта, а не рекомендации или допустимые дорожные ограничения. US: 13 ft 6 in × 8 ft 6 in × 60 ft, 80000 lb, 5 осей. Metric: 4.1148 × 2.5908 × 18.288 m, 36287.3896 kg. Это готовые пары строк, не новый конвертер. Габариты относятся ко всему транспортному средству/составу; масса включает груз, топливо и людей; оси включают все установленные, в том числе подъёмные. Карточка главной пока показывает US независимо от режима просмотра формы.

Кнопки над экранами предназначены для просмотра дизайна и не входят в приложение. После изменения единиц/типа Save снова недоступен. Перезагрузка сбрасывает состояние.

## Визуальная основа

- Основной текст/структура: navy `#102d40`.
- Действия: forest green `#235740`, белый текст.
- Вторичный текст: `#536675`.
- Акценты: lime `#d4e7ad`, мягкая подложка `#edf3e8`.
- Фон: `#f4f5f0`, поверхности: `#ffffff`, границы: `#dce2df`.
- Системный sans-serif; заголовки 20–29 px, основной текст 12–14 px, вспомогательный 10–11 px. Эти размеры требуют отдельной проверки с системным увеличением шрифта в RN.
- Основные кнопки 46–50 px; переключатели единиц 44 px. Остальные элементы и native touch targets необходимо проверить при переносе.

Использован существующий PNG-логотип v1. Новые launcher icons и юридическая проверка знака не входят в эту итерацию. Светлое дневное направление; тёмная тема пока не спроектирована.

## Проверки и границы

Локальный Chrome/Playwright: переходы между экранами, смена типа и названия карточки, обе пары единиц, Validate → Save → уведомление, сброс Save после смены типа, недоступность входа, readonly email/password, загрузка логотипа, отсутствие JS page errors. Горизонтальный overflow страницы проверен при ширине 320/390/768/1440 px. Просмотрены снимки desktop overview и mobile profile 390 px. Это не проверка полноты видимости текста внутри каждого поля на всех ширинах.

Не выполнены: Android/iOS сборки и native UI тесты для этого макета, физические устройства, VoiceOver/TalkBack, крупный шрифт, полный аудит контраста, dark mode, реальный вход/сессии/восстановление пароля, маршрутизация и расчёт экономии. Существующие тесты приложения повторно не запускались: исходники приложения не менялись.

## Следующая отдельная задача

Перенести тему и экран профиля в React Native с сохранением точных строк, доменной валидации, локального хранения и native iOS input adapter. Проверить состояния пусто/ошибка/проверен/сохранён, клавиатуру и увеличенный шрифт.

После этого — отдельная задача авторизации: выбрать провайдера по официальной документации, определить регистрацию, подтверждение контакта, восстановление, завершение/истечение сессий и ошибки. Реализовать интерфейс/адаптер и тесты до серверного хранения профилей пользователей; не хранить токены в текущем нешифрованном хранилище профиля.
