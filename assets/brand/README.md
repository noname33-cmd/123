# Truck Route & Savings — logo v1

Концепция: грузовик, дорога и стрелка вперёд. Тёмно-синий обозначает надёжность, зелёный — эффективность. Это растровый концепт с прозрачным фоном, не готовый набор Android adaptive/iOS app icons. В мобильный экран и native launcher icons пока не подключён. Проверка товарных знаков и читаемости во всех размерах не проводилась.

Файл: `truck-route-savings-logo-v1.png`. Сгенерирован встроенным image_gen, без CLI/API-ключей. Результат просмотрен визуально: один символ, без текста, грузовик и дорога различимы. Для маленьких launcher icons может потребоваться упрощение деталей.

Точный prompt:

> Use case: logo-brand. Create an original professional logo symbol for Truck Route & Savings, a mobile app for American truck drivers. A bold simple road curving into a forward arrow, integrated with a minimal truck cab silhouette; communicate dependable travel and efficiency. Flat vector-like geometry, strong clean silhouette legible at app-icon sizes, restrained navy with green accent. One centered symbol only, no text, no lettering, no mockups, no shadows, no watermark. Transparent background with generous clear padding.
